查看角色会想起什么

输入受众范围，可预览当前会话能召回的记忆，或查看某个人的长期画像。这不会发消息，也不会强化记忆。

近期容量与强化规则

recent_capacity / recent_per_scope 限制普通 FIFO 区；protected_capacity / protected_per_scope 限制保护区，两区容量相加。daily_reward_limit 是滚动 24 小时上限。缩容在下一次清醒维护或记忆写入时整理。

遗忘这段来源及派生记忆

相关旧版本、依赖它的插件缓存和待发送草稿会被清理，活动需要重建上下文。原始聊天日志保留，但不再注入上下文或从这些旧来源提炼记忆。已经发出的消息无法撤回。
